Feedstock for [fastnlo](https://fastnlo.hepforge.org) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

FastNLO: fast pQCD calculations for hadron-induced processes

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/fastnlo](https://anaconda.org/hep-forge/fastnlo).


## Install

```bash
conda install -c hep-forge -c conda-forge fastnlo
```
